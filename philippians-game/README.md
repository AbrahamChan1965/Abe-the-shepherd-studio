# 以巴弗提的旅程 · 腓立比书圣经游戏

单一 HTML 文件，用浏览器直接打开 `index.html` 即可游玩（手机 / 电脑皆可）。经文采用和合本（简体）。

## 结构
| 幕 | 经文 | 玩法 |
|---|---|---|
| 序幕 · 去程 | 4:2、1:28、2:27 | 背着重担横向闯关，结党 / 嫉妒 / 纷争 / 怨言化作病菌；凭自己反击只会让病菌分裂（加 5:15），最终倒在罗马城门前 |
| 转折 | 2:27、2:13 | 「然而神怜恤他」——解锁「等候」（圣灵连接） |
| 第一章 · 罗马 | 1:12-27 | 五个处境选择；顺着圣灵的路要先等候、被光照才看得见 |
| 第二章 · 谦卑阶梯 | 2:3-15 | 沿基督虚己的九级阶梯向下走，每一级扎根并结出谦卑中的一种果子（加 5:22-23） |
| 第三章 · 标竿 | 3:5-14、4:8 | 跑酷：等候让圣灵照出资历包袱（最深是「自以为义」）并丢弃；接住 4:8 的思念；不要回头 |
| 第四章 · 回程 | 4:2-7、3:20 | 同一条路、同样的病菌，这次可举起「平安」的盾（4:7） |
| 终章 | 4:4-13 | 生命树结算与小组分享问题 |

## 研经判断
- 1:15-17 嫉妒纷争的传道发生在保罗被囚之地（罗马），这是 Fee、O'Brien、Bockmuehl 等注释的主流看法；1:17 与 2:3 的「结党」（ἐριθεία）呼应腓立比教会自身的问题。
- 以巴弗提的病因经文未交代，「病菌」是属灵寓意。
