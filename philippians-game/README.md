# 以巴弗提的旅程 · 腓立比书圣经游戏

单一 HTML 文件，用浏览器直接打开 `index.html` 即可游玩（手机 / 电脑皆可）。经文采用和合本（简体）。

## 结构
| 幕 | 经文 | 玩法 |
|---|---|---|
| 序幕 · 去程 | 4:2、1:28、2:25-30 | 三关各争战 60 秒，都躲不过：病菌一波比一波厚，只能争战；每击碎一个就沾染一点，硬冲过去沾染更深。迎面而来的油和水是圣灵的供应（1:19）：水退烧，油使争战时沾染得少。按病情轻重，有三种到达罗马的画面：倒在保罗门口、爬到城门、被弟兄抬进罗马 |
| 转折 | 2:27、2:13 | 「然而神怜恤他」——解锁「等候」（圣灵连接） |
| 第一章 · 罗马 | 1:12-27 | 五个处境选择；顺着圣灵的路要先等候、被光照才看得见 |
| 第二章 · 代赎的阶梯 | 2:5-13、林后 8:9、罗 8:26、加 4:6 | 开场先选角色（孩子／父母／照顾年老父母的人／长辈／一家人一起）。不是我们学着往下走，是基督为我们一级一级降到家里九个处境：身份、控制、倦怠、照顾、误解、认错、孝道、哀伤、代代相传的伤。长按约 20 秒「让祂降下来」，浮现经文、问题、圣灵在里面的祷告、基督成就的代赎结果；「我自己来」会剧烈摇晃。第 6、7、9 级有牧养护栏，第 9 级附中国大陆求助资讯 |
| 第三章 · 标竿 | 3:5-14、4:8 | 资历一排一排、一个方阵一个方阵迎面而来，碰到就像蛛网缠身；用力挣脱越缠越紧。只有抓住从上面来的 4:8 之光（附希腊文字义），手才松开旧的。最深的「自以为义」任何美德都松不开，只能等候，让「至宝」基督来得着你（3:8-12）；不要回头 |
| 第四章 · 回程 | 4:2-9、3:20-21 | 同一条路、同样的病菌，带着前三章领受的回家。平安一开始就守着他，病菌会把它打薄；抓住从上面飘下的 4:8 之光，平安就加厚（4:9）；只靠持守会慢慢变薄。进城前有约 40 秒的「思念」练习，把八样应用到两位姊妹身上，然后带着平安去见她们 |
| 终章 · 未完 | 1:3-6、2:2、2:29、4:2 | 会众一起读信，读到两姊妹的名字时停住。是否和好、生命树会否长起来都留白，以 1:6 作结；列出保罗十三卷书信作为后续系列 |

## 研经判断
- 1:15-17 嫉妒纷争的传道发生在保罗被囚之地（罗马），这是 Fee、O'Brien、Bockmuehl 等注释的主流看法；1:17 与 2:3 的「结党」（ἐριθεία）呼应腓立比教会自身的问题。
- 以巴弗提的病因经文未交代，「病菌」是属灵寓意。
