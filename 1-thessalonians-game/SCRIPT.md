# 《帖撒罗尼迦前书》点灯游戏 · 剧本（第五版）

> 本剧本依据 DESIGN.md「第五版方向」，以及已确认的原型 `prototype-night.html`。
> 剧本是给制作的人看的：可以说明设计用意。玩家看到的文字，只有每一场「屏幕文字」那一栏。
> 经文用和合本。发布前要用纸本和合本逐字核对一次，见文末总表。

---

## 体例

**一条规矩：意思要靠手做出来，不靠读出来。**

- 每个画面最多一行字，加一处经文出处。
- 语音（朗读）只在三个地方出现：开场的人物卡、念信之夜、结尾。
- 新手势第一次出现时，用一只淡淡的白圈手指示范，不写说明。
- 没有「游戏结束」画面。熄了的灯不算输。

每一场写七项：

| 项目 | 内容 |
|---|---|
| 时长 | 第一次玩的人大约需要的时间 |
| 画面 | 玩家看到什么 |
| 手势与规则 | 玩家做什么，世界怎么回应 |
| 屏幕文字 | 玩家看得到的全部文字 |
| 语音 | 朗读的内容（没有就不写） |
| 经文依据 | 这一场根据哪几节 |
| 设计注 | 为什么这样做；给制作的人看 |

## 基本元素（全剧共用）

| 元素 | 画面 | 意思 |
|---|---|---|
| 灯 | 小陶灯，一户人家一盏 | 信徒、家庭教会 |
| 器皿 | 画面下方的陶罐 | 按住才有油：等候、祷告、领受 |
| 手指上的油 | 按下时手指周围的金光 | 你能给出去的，只有领受来的 |
| 家的淡圈 | 每盏灯原来位置的虚线圈 | 行列、本分（4:11「办自己的事」） |
| 风 | 从城边吹进来的白色气流 | 本地人的苦害（2:14） |
| 火把 | 一群红色的光点 | 暴民（徒 17:5） |
| 余烬 | 熄了的灯留下一点暗红 | 睡了的人（4:13） |
| 雾 | 保罗那边，看向北方的一层灰 | 面目离别，不知道消息（2:17；3:5） |

### 五种状况与手势（城里）

| 灯的样子 | 手势 | 经文 |
|---|---|---|
| 火苗缩小、发抖 | 按住护着 | 勉励灰心的人（5:14） |
| 灯慢慢歪倒 | 往上托 | 扶助软弱的人（5:14） |
| 灯离开淡圈往外飘 | 拖回淡圈 | 警戒不守规矩的人（5:14；「不守规矩」原是军队「出列」的字） |
| 风吹过来 | 手指挡在风前 | 免得有人被诸般患难摇动（3:3） |
| 有人睡了，旁边的灯垂下 | 画圈把几盏灯圈起来 | 彼此劝慰（4:18；5:11） |

每个手势都要用手指上的油。没有油就什么都做不了，只能回到器皿那里。

## 结构与时长

| 段落 | 地点 | 时长 | 主要手势 |
|---|---|---|---|
| 序：灯从哪里来 | 帖撒罗尼迦 | 1 分钟 | 按住器皿 |
| 第一幕：点灯 | 帖撒罗尼迦 | 6 分钟 | 等候、点灯、护灯、拖 |
| 第二幕：孤儿之夜 | 城里三夜，穿插保罗三段 | 18 分钟 | 全部城里的手势；节拍点按、推、拖 |

## 序：灯从哪里来

**时长**：1 分钟

**画面**
- 全黑。
- 远处一点光沿着大道从东边走来：保罗、西拉、提摩太从腓立比来，带着伤（2:2）。
- 光停在城门口。城里的屋顶隐约出现，屋里没有一盏灯，只有几座神像发出冷冷的青光。

**手势与规则**
- 器皿出现，白圈示范按住。
- 按住时，光从上面倒进器皿。

**屏幕文字**
- 「不独在乎言语，也在乎权能和圣灵。」（帖前 1:5）

**语音**：人物卡（见上）。

**经文依据**：1:5；2:2；徒 17:1。

**设计注**
- 第一个动作不是点灯，是等候。
- 整个游戏的地基在第一秒就放下：光不是从玩家来的。

## 第一幕：点灯

### 1-1 三个安息日

**时长**：3 分钟

**画面**
- 八户人家是暗的。
- 有几户门口有青光的神像。
- 远处的会堂有一盏稳定的灯：保罗在那里讲道。
- 天色走过三次「安息日」：画面暗一下，再亮回夜色。

**手势与规则**
- 手指带着油碰一户暗的人家，那里就点起一盏灯。
- 有神像的人家，神像的青光会先抖一下，然后熄掉、倒下。
- **有些人家玩家碰了也不亮**，过一会儿自己亮了。也有一两户始终不亮（不信的人家，画面上仍有房子）。
- 八盏灯不一定由玩家点亮。会堂的灯每过一个安息日，自己也会点亮一两盏。

**屏幕文字**
- 「离弃偶像归向神，要服侍那又真又活的神。」（帖前 1:9）

**经文依据**：徒 17:2-4；帖前 1:5、1:9；2:13「这道……运行在你们信主的人心中」。

**设计注**
- 谁信、谁不信，不由玩家的手决定（DESIGN.md 研经判断）。
- 玩家第一次碰到「我做了，却不是我成就的」。

### 1-2 昼夜做工

**时长**：1 分钟（过场，可略过）

**画面**
- 皮革街的作坊亮着一盏灯，那是保罗在做工。
- 白天和夜晚快速交替，作坊的灯始终亮着。
- 来来往往的小灯在作坊门口停一停又走，那是信徒来看保罗。

**手势与规则**：没有手势，玩家看着就好。手指碰作坊，会听见针穿过皮子的声音。

**屏幕文字**
- 「昼夜做工，传神的福音给你们。」（帖前 2:9）

**经文依据**：2:7-12；腓 4:16。

**设计注**：这一场为第二幕保罗缝帐棚铺路。

### 1-3 暴乱之夜

**时长**：2 分钟

**画面**
1. 市场上聚起一团红色火把。
2. 一支火把从皮革街出发，走到市场，再领着火把群走向耶孙家。这是叔父狄奥多罗，画面上不写他的名字。
3. 保罗和西拉的灯藏在耶孙家后面。

**手势与规则**
1. **护灯**：火把经过时，玩家用手盖住保罗和西拉的灯，挡住光，不被看见。这是城里「按住护着」的第一次出现，在这里的意思是遮藏。
2. **耶孙家**：火把围住耶孙家。耶孙的灯被拉向市场，最后回来了，但灯身多了一道裂痕（保状）。这一段玩家不能操作，只能看。
3. **送走**：天还没亮，白圈示范：把保罗和西拉的灯拖向西门。拖出城门后，灯越走越远，越来越小，最后看不见。

**屏幕文字**
- 「弟兄们随即在夜间打发保罗和西拉往庇哩亚去。」（徒 17:10）

**经文依据**：徒 17:5-10；帖前 2:14-17。

**设计注**
- 叔父是「出于好意而做错了事」：他怕骚乱烧掉整条皮革街。所以只用一支走路的火把呈现，不画成恶人，也不加文字。
- 耶孙家那道裂痕，在第二幕「北边被挡」时会再出现一次，作为不下定论的提示（研经判断第 5 条）。
- 玩家亲手把保罗送走：留下的人是用自己的手放手的。

## 第二幕：孤儿之夜

> 「我们暂时与你们离别，是面目离别，心里却不离别。」（2:17）
> 「离别」原文是「成了孤儿」。

本幕由「城里一夜」和「保罗一段」交替进行：

城里第一夜 → 雅典 → 城里第二夜 → 哥林多 → 城里第三夜 → 好消息

### 全幕共用的规则：你护不了自己的灯

- 亚里达古的灯是玩家自己的。玩家可以照顾其他七盏，**唯独不能照顾自己这一盏**：按住、托、拖，都对它没有作用。
- 别人的灯离它近、而且够亮时，会自己伸出一道光，扶它一下（4:9）。
- 设计用意是 5:11「彼此劝慰，互相建立」：没有人能只当照顾者。
- 这条规则还没有在原型里验证。试玩时要看玩家会不会以为是程序出错。若会，就在第一次碰自己的灯时，让旁边的灯伸出光来，代替说明。

### 2-1 城里第一夜

**时长**：3 分钟

**画面与规则**
- 和 `prototype-night.html` 相同：器皿、灰心（发抖）、软弱（歪倒）、出列（飘走）、风。
- 新手势依次出现，各自有白圈示范：
  - 0:08 灰心
  - 0:26 软弱
  - 0:42 出列
  - 0:52 第一阵风
- 不在原型里、本夜新加的两项：
  - **西公都**：他的灯不抖、不歪、不飘，只是慢慢暗下去，没有白圈提醒。玩家要自己留意到。
  - **问题的火星**：玩家护住一盏灯时，偶尔会从灯里升起一颗淡蓝色的小火星，停在灯的上方。火星不用处理，它会一直留着。这是城里人心里的问题，提摩太后来会把它带走。

**屏幕文字**
- 天亮时：「你们自己知道我们受患难原是命定的。」（帖前 3:3）

**经文依据**：3:3；5:14；2:14。

**设计注**：西公都对应作者的设定，钟形曲线中间那个「众人」：可靠、安静，没人留意时，他的灯会慢慢暗下去。5:14 最后一句「也要向众人忍耐」，落在没有警报的那一盏灯上。

### 2-2 雅典：撒但阻挡了我们

**时长**：3 分钟

**画面**
- 换成保罗这边。画面是雅典：满城白色的神像。
- 保罗的灯在神像中间，旁边是提摩太的小灯（西拉暂时不在）。
- 北方是一片灰雾，雾里隐约看得见几点光，看不清有几盏。

**手势与规则**
1. **往北推**：白圈示范，把保罗的灯往北推。推到雾的边缘，一道暗墙把灯推回来。第二次再推，又被推回来。第三次推不动，墙一动也不动。
   - 墙的表面，隐约有耶孙家那道裂痕的纹路。
2. **祷告**：保罗回不去。白圈改为示范按住雾。按住时，雾里那几点光会亮一下，但雾不会散。
3. **打发提摩太**：白圈示范，把提摩太的小灯拖进雾里。
   - 拖进去以后，保罗身边只剩他自己一盏。
   - 保罗的灯暗了一点，因为他「独自」。
   - 这一步是必经的：不拖，这一段不会结束。

**屏幕文字**
- 推墙时：「我保罗有一两次要去，只是撒但阻挡了我们。」（帖前 2:18）
- 拖走提摩太后：「我们既不能再忍，就愿意独自等在雅典。」（帖前 3:1）

**经文依据**：2:17–3:5；徒 17:16。

**设计注**
- 墙是什么，游戏不说。可能是保状的条件，也可能是反对者追来（徒 17:13）。经文只说「撒但阻挡」。
- 第二次推墙和第三次推墙，手感不同（第三次完全推不动）。这是「一两次」的分寸，再推下去就变成玩家在跟程序作对。
- 保罗能做的只有祷告、打发人、写信，这正是 DESIGN.md 支柱一说的：保罗那边最能体现「不是靠人」。

### 2-3 城里第二夜：埃拉睡了

**时长**：4 分钟

**画面与规则**
1. **提摩太来了**：夜一开始，提摩太的小灯从城门进来。
   - 他会自己走到最暗的那盏灯旁边，停一会儿，让那盏灯亮起来，再走向下一盏。
   - 玩家多了一双手，不用指挥他。
   - 他经过的灯，头上的问题火星会被他收走，跟着他走。
2. **埃拉睡了**：大约 1 分 40 秒，尼肯家的灯里，小的那一朵火苗熄了，变成一点余烬。尼肯家的灯一盏变两盏：大的是尼肯，小的是埃拉的余烬。
   - 附近几盏灯垂下来，越来越暗。
   - 白圈第一次示范画圈：把垂下的灯圈起来。圈起来以后，它们彼此照亮，不再往下掉。
3. **尼肯的分辨**：埃拉睡了以后，尼肯的灯开始往外飘，同时又在发抖。
   - 只把它拖回来，过一会儿它又会飘出去。
   - 要先按住护着它，等它不抖了，再拖回淡圈，它才会留下。
   - 这一处没有白圈示范，让玩家自己发现。

**屏幕文字**
- 余烬出现时，没有文字。
- 天亮时：「又愿主叫你们彼此相爱的心，并爱众人的心，都能增长、充足。」（帖前 3:12）

**经文依据**：3:2「坚固你们，并在你们所信的道上劝慰你们」；4:13；5:14。

**设计注**
- 尼肯一段直接来自作者的设定：他在市场上宣讲末日、不做工，根源是丧女之痛。表面是不守规矩，里面是灰心。
  - 作者原设定写「丧子之痛」，但同一份设定里埃拉是尼肯的小女儿，这里写「丧女」。若作者原意不同，再改回。
- 5:14 要分辨三种人：只用一种手势对付，是会失败的。游戏不说这个道理，让手去试出来。
- 埃拉的余烬没有文字，也没有音乐变化。只有安静，和旁边垂下来的灯。这一夜玩家手里没有任何手势能让余烬复燃，这就是 3:10「补满你们信心的不足」。

### 2-4 哥林多：缝帐棚

**时长**：3 分钟

**画面**
- 哥林多的作坊。保罗、亚居拉、百基拉三盏灯围着一块帐棚布。
- 画面中间是一条缝线。针沿着线一格一格移动，到亮区时点下去，就缝好一针。

**手势与规则**
- **节拍点按**：跟着针的节拍点下去。
  - 轻度：亮区宽、针慢。
  - 中度：亮区窄、针快。
  - 点错不扣分，只是那一针缝歪了。
- **独自缝**：亚居拉和百基拉白天在旁边，晚上回家。到晚上只剩保罗一盏灯，节拍变快一点，亮区变窄一点。这是打发提摩太的代价：身边少一双手（3:1）。
- **北方的雾**：画面右上角一直有一小块北方的雾。缝的时候，雾的颜色时浓时淡，保罗看不清楚。
- **一块帐棚缝完**：哥林多城里亮起一点新的小灯（徒 18:4「每逢安息日，保罗在会堂里辩论」）。

**屏幕文字**
- 开始时：「他们本是制造帐棚为业。」（徒 18:3）

**经文依据**：2:9；徒 18:1-4；林前 4:12。

**设计注**
- 这是唯一一段要节奏感的玩法，也是给长辈的手指运动。
- 缝得好坏不影响城里，只影响哥林多这边亮起几盏小灯。玩家会感受到：保罗做工是为了不叫人受累（2:9），不是为了在城里赚分数。

### 2-5 城里第三夜：加力普睡了

**时长**：4 分钟

**画面与规则**
- 风比前两夜多，也更急。
- 提摩太还在城里，继续帮忙。

**加力普睡了**
- 大约 1 分钟，加力普家那盏灯里，年轻的那一朵火苗熄了，留下余烬。
- 加力普原本是最亮、最常往城门口跑的一盏灯。他的口头禅「等主来了，我第一个跑去迎接」，用画面表现：前两夜，他的灯常常自己往东边城门那里靠。
- 余烬旁边，问题的火星一下子升起好几颗：
  - 「睡了的人怎样？」
  - 「主什么时候来？」
- 火星不显示文字，只是颜色更深的蓝。

**红灯笼**
- 城边亮起一盏红色的灯笼，暖得太过分。
- 有一盏灯会被它慢慢吸过去。这盏灯和「出列」不同：它不是往外飘，而是直直地朝灯笼滑过去，越靠近滑得越快。
- 拖回淡圈没有用，一放手又滑回去。
- **要用画圈把它和别的灯圈在一起**，它才会停下来。
- 没有文字。

**提摩太南下**
- 天快亮时，提摩太的小灯会把全城的问题火星收齐，从城门往南走出去。
- 玩家不用操作。

**屏幕文字**
- 天亮时：「我们昼夜切切地祈求，要见你们的面，补满你们信心的不足。」（帖前 3:10）

**经文依据**：3:6-10；4:3-8；4:13；5:1。

**设计注**
- **红灯笼对应 4:3-8「远避淫行」**。
  - 作者要求真实呈现情欲的挣扎。在这个只有图像的版本里，用一个人独自抵挡不住的「拉力」来表现：靠自己（拖回来）不行，要在弟兄姊妹中间（画圈）才站得住。
  - 亚里达古过去与菲丽娜的事（作者设定），留给目录的「人物卡」以文字交代，不放进夜里的画面。
- 加力普的死，接在埃拉之后。这一次，**玩家知道画圈可以止住垂下的灯，却仍然没有办法让余烬复燃**。问题火星升起来，玩家和城里的人一样，等一个回答。

### 2-6 哥林多：好消息

**时长**：1 分钟（过场）

**画面**
1. 保罗在哥林多缝帐棚，右上角的北方仍是雾。
2. 提摩太的小灯从北边回来，西拉也一起回来（徒 18:5）。
3. 提摩太走到保罗身边，雾慢慢散开。保罗第一次看清楚北方：城里的灯，就是玩家刚才三夜之后真正留下的样子。
4. **不管留下几盏，保罗的灯都会亮起来**，而且比前面任何时候都亮。

**屏幕文字**
- 「你们若靠主站立得稳，我们就活了。」（帖前 3:8）

**经文依据**：3:6-9；徒 18:5。

**设计注**
- **保底**：若三夜之后亮着的灯不到一半，恩典（自己亮起来的灯）会在第三夜后段补到至少一半。这件事不告诉玩家。
- 理由：
  - 3:6 记载的确是好消息，是「信心和爱心的好消息」。
  - 教会站立得稳，是「靠主」，不是靠玩家手快。
- 试玩记录里，要分开记「玩家自己守住的」和「恩典补上的」，供作者判断保底合不合适。

## 第三幕：信到了

### 3-1 口述

**时长**：3 分钟

**画面**
- 哥林多的夜。保罗的灯、西拉、提摩太，以及执笔人亚挪尼摩的一盏小灯。亚挪尼摩面前有一卷空白的皮纸。
- 提摩太带回来的问题火星，在空中慢慢飘。

**手势与规则**
- 把一颗火星拖到皮纸上，皮纸就写出一段，语音读出那一段的头一句。
- 每颗火星只会落到对应的那一段，不会出错，所以这一段不是配对题。玩家只是把城里的问题，亲手交到保罗的信里。

| 火星从哪里来 | 写出的段落 | 读出的第一句 |
|---|---|---|
| 余烬旁边的深蓝火星 | 4:13-18 | 「论到睡了的人，我们不愿意弟兄们不知道……」 |
| 「主什么时候来」的火星 | 5:1-11 | 「弟兄们，论到时候、日期，不用写信给你们……」 |
| 出列和尼肯的火星 | 4:9-12 | 「论到弟兄们相爱，不用人写信给你们……」 |
| 红灯笼旁边的火星 | 4:3-8 | 「神的旨意就是要你们成为圣洁，远避淫行。」 |
| 西公都那盏（若玩家曾经护过他） | 5:12-15 | 「我们又劝弟兄们，要警戒不守规矩的人……」 |

- 火星都落下以后，保罗自己在皮纸最前面加上第 1–3 章：开头的问安和感谢。画面是皮纸自己向上展开很长一截。
- 皮纸卷起，封好。

**屏幕文字**
- 「保罗、西拉、提摩太写信给帖撒罗尼迦在父神和主耶稣基督里的教会。」（帖前 1:1）

**语音**：如上表，各段的第一句。

**经文依据**：全书结构（1–3 章回顾与感谢；4–5 章回答与劝勉）。

**设计注**
- 玩家会看见：这封信里的话，是从城里那几夜长出来的。
- 帖前是一封完整的信（RESEARCH.md），所以保罗回答了每一个问题，不让玩家挑。
- 若玩家从没护过西公都，那颗火星就不会出现。5:12-15 仍然会写进信里，因为保罗看得见玩家看不见的。

### 3-2 信差的路

**时长**：4 分钟

**画面**
- 真实地图，现代清楚的风格（沿用第三版地图资料）。
- 路线从哥林多出发，经地峡、底比斯、温泉关、拉里萨、坦佩峡谷、彼得那，到帖撒罗尼迦，约 520 公里。
- 信差克莱翁的小灯，背着封好的信。

**手势与规则**
- **用手指沿路描**：描到哪里，灯就走到哪里。
  - 轻度：路线粗，偏离会自动吸回。
  - 中度：路线细。
  - 另有「按住前进」，手不稳的玩家也能走完。
- **日夜**：每走一段，天空就过一天一夜，全程约二十个日夜，用天色变化表现，不显示数字。
- **小窗**：画面角落有一个很小的帖撒罗尼迦，几盏灯在里面亮着。信差每多走一天，小窗里就有灯微微变暗。描快一点，不会快多少，这是步行的速度。
- **路上的事**（各几秒钟，没有失败）：
  - 坦佩峡谷的河水要等一等。
  - 夜里在路边的客店。
- **地名卡**：点一下地名，出现古名、今名，还有「看今天的样子」，在浏览器里打开谷歌地图。

**屏幕文字**
- 出发时：「我指着主嘱咐你们，要把这信念给众弟兄听。」（帖前 5:27）

**经文依据**：5:27；DESIGN.md 第六段地图；RESEARCH.md 信差与路线。

**设计注**
- 这一段的「慢」是故意的。玩家已经知道城里的灯在暗下去，却只能一步一步走。这就是那个时代的书信。

### 3-3 念信之夜

**时长**：4 分钟

**画面**
1. 信差的灯进城，走到耶孙家。
2. 城里还亮着的灯，自己一盏一盏聚到耶孙家，包括尼肯，也包括西公都。
3. 余烬也被别的灯带着，一起来。
4. 皮纸展开。

**手势与规则**
- 语音念信。玩家每点一下皮纸，就念下一段。
- 念到某些段落时，城里的规则当场改变，玩家在画面上看得见：

| 念到 | 规则的改变 | 画面 |
|---|---|---|
| 1:2-10 | 没有改变，只是念 | 灯一盏一盏亮一下 |
| 3:6-8 | 没有改变 | 保罗那边的灯在地图远处亮了一下 |
| 4:9-10 | **灯会彼此照顾**：够亮的灯碰到垂下的邻灯，会自己伸光扶它一下，比以前更常发生 | 灯与灯之间出现细细的金线 |
| 4:11-12 | 出列的灯飘得比较慢；被拖回淡圈后，会留得比较久 | 淡圈变得清楚 |
| 4:13-18 | **余烬变色**：从暗红变成温暖的金色，不再让旁边的灯垂下 | 余烬短暂地往上升一点，像要被提起来，然后安静落回原处 |
| 5:5-8 | 风吹到够亮的灯时，伤得比较轻 | 灯身出现一层薄薄的光 |
| 5:14 | 灰心、软弱、出列的灯，变得比较容易分辨（发抖、歪倒、飘走的样子更清楚） | — |
| 5:16-18 | 手指不在器皿上时，也会有一丝细细的油慢慢流进来。按住器皿仍然快得多 | 器皿和手指之间有一条细线 |
| 5:19 | 有人圈在一起的灯，风再大也不会被吹熄，最多吹暗 | — |
| 5:23-28 | 没有改变 | 全部的灯一起亮一下 |

**屏幕文字**：念到哪一段，就在画面下方显示那一段的出处，例如「帖前 4:13-18」。

**语音**：全信朗读（和合本），约 8 分钟。可以点一下跳到下一段。
- 第一次玩的人，可以选「只念有改变的段落」，大约 3 分钟。

**经文依据**：5:27；全书。

**设计注**
- 信不是「奖品」，也不是天赋树。它是一封完整的信，念给众人听（5:27）。
- 规则的改变都是「教会彼此」的改变，以及「盼望」的改变。玩家的手没有因为信而变强，**变强的是众灯彼此之间**。这就是 4:9 和 5:11。
- 4:13-18 这一处，余烬往上升一点、又落回来：这是应许，还没有发生。主还没有来。

### 3-4 最后一夜

**时长**：5 分钟左右（玩家不知道多长）

**画面与规则**
- 所有手势、所有状况都会出现，加上念信之后的新规则。
- 这一夜的长度不固定：轻度 3 到 5 分钟，中度 4 到 6 分钟，每次不同。
- 没有任何提示告诉玩家快天亮了。天色在最后十几秒才开始变，然后很快就亮了。

**屏幕文字**
- 夜一开始：「主的日子来到，好像夜间的贼一样。」（帖前 5:2）
- 天亮时：「你们都是光明之子，都是白昼之子。」（帖前 5:5）

**经文依据**：5:1-11。

**设计注**
- 主的日子像贼，所以玩家不能「撑到时间结束」，只能每一刻都醒着。
- 天亮的是一个平常的早晨，不是主再来。灯还在，余烬还在，患难也还没过去。

## 尾声：那召你们的

**时长**：1 分钟

**画面**
1. 帖撒罗尼迦的早晨。灯一盏一盏熄掉，因为天亮了，不需要了。余烬仍是金色。
2. 镜头拉远，越过地图，到哥林多。保罗的灯在作坊里，仍在缝。
3. 他抬头看北边：已经没有雾了。

**屏幕文字**
- 「那召你们的本是信实的，他必成就这事。」（帖前 5:24）

**语音**：只念这一句。

**之后**：出现「再玩一夜」和「目录」两个按钮，以及试玩记录。

**设计注**
- 结局保持未完：保罗没有回来，患难没有过去，主也还没有来。
- 最后一句是 5:24。成就这事的是神，不是玩家。

## 待试玩验证的问题

1. 「你护不了自己的灯」会不会被当成程序出错？
2. 尼肯「先护再拖」，没有白圈示范，玩家能不能自己发现？
3. 西公都没有警报，玩家几夜之后会不会留意到他？
4. 红灯笼的「拉力」，画圈能止住这件事，玩家试几次才会想到？
5. 第二幕结尾的保底（恩典补到一半），会不会让会玩的人觉得自己的努力没有意义？
6. 念信之夜，长辈愿意听完全信，还是只听有改变的段落？
7. 最后一夜长度不固定，会不会让人觉得不公平？还是正好表达了 5:2？
