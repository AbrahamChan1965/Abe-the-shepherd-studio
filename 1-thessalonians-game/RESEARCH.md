# 帖撒罗尼迦书信 · 研究笔记

> 用途：作为游戏设计的史料与学术基础。不确定的地方都标明「推测」「有争议」。
> 经文引自和合本；年代为约略，多数依据迦流铭文推算。

---

## 一、帖撒罗尼迦前书是一封信，还是书信合集？

### 1. 学界主要立场

| 立场 | 代表 | 主要论点 | 现状 |
|---|---|---|---|
| **帖前是一封完整的信** | Jewett、Wanamaker、Malherbe、Fee、Weima、Green 等 | 两次感恩（1:2、2:13）和 3:11-13 的祝祷，可以用古代书信与修辞结构解释；全信的用词、主题（信望爱、主再来）前后连贯 | **主流共识** |
| 帖前由两封信拼成 | Schmithals、Richard 等 | 2:13 第二次感恩、3:11-13 像结尾的祝祷，后面又接 4:1 的劝勉，看起来像两封信的接缝 | 少数说 |
| 2:13-16（或 2:14-16）是后人插入 | Pearson（1971） | 对犹太人的严厉话语（「神的忿怒临在他们身上已经到了极处」）像是主后 70 年圣殿被毁之后的口吻 | 少数说；多数注释认为是保罗原文，用先知控诉的传统解释 |

**判断**：游戏以「帖前是一封完整的信」为前提，这是学界共识。2:14-16 照原文处理，不加戏、不把犹太人塑造成反派（沿用设计文件第八节）。

### 2. 帖前和帖后的关系

| 问题 | 主要看法 |
|---|---|
| 帖后是不是保罗写的？ | **有争议**。Wrede（1903）、Trilling（1972）等认为是后人托名；Malherbe、Wanamaker、Fee、Weima、Green 等认为是保罗写的 |
| 争议点 | 末世论的差别：帖前说主的日子「像夜间的贼」突然来到（5:2）；帖后说在那日以前，先有「离道反教的事」和「大罪人」显露（2:3）。另外帖后 2:2 提到「冒我名的书信」，3:17 又强调「凡我的信都以此为记」 |
| 哪一封先写？ | 多数认为帖前在先；Wanamaker 主张帖后在先（少数说） |
| 若是保罗写的，相隔多久？ | 一般估计帖后在帖前之后几个月，也在哥林多写成 |

**对游戏的意义**：
- 帖前和帖后是**两封信**，不是一部合集。本卷游戏只做帖前，帖后留给工作室下一卷。
- 但两封信之间有一条现成的故事线：帖后说「我们听说，在你们中间有人不按规矩而行」（帖后 3:11），可见**有人把帖撒罗尼迦的近况带回给保罗**。本作的信差送完信、带着消息回哥林多，正好接上下一卷。

### 3. 一个值得采用的学术推测：教会也写了信给保罗

- 帖前 4:9、4:13、5:1 都用「论到……」（希腊文 περὶ δέ）开头。保罗在林前 7:1 回答哥林多人「论到你们信上所提的事」时，用的正是同一个开头。
- 因此有学者（Faw、Malherbe 等）推测：**提摩太回哥林多时，可能带着帖撒罗尼迦教会写的一封信或一串问题**。也有人认为这只是保罗转换话题的说法。
- **游戏处理**：用「提摩太的皮袋里装着教会的问题」来呈现，不说死是一封正式的信。这已在现行版本中使用。

## 二、写信的人：主后 50 年前后，在哥林多的保罗

### 1. 年代的锚点

- **迦流铭文**（德尔斐出土，革老丢皇帝的书信）显示，迦流约在主后 51–52 年任亚该亚省方伯（徒 18:12）。
- 保罗在哥林多住了一年零六个月（徒 18:11），所以约在主后 50 年初到达哥林多。
- 帖前写于提摩太和西拉从马其顿来到之后不久（徒 18:5；帖前 3:6），约主后 50 年。

### 2. 保罗身边的人和事（徒 18 与书信）

| 人或事 | 出处 | 游戏可用 |
|---|---|---|
| 亚居拉、百基拉：从罗马来的犹太夫妇，做帐棚 | 徒 18:2-3 | 作坊是保罗的工作和住处 |
| 革老丢命犹太人离开罗马 | 徒 18:2；苏维托尼乌斯《革老丢传》25.4（「因基利斯督〔Chrestus〕的缘故不断骚乱」）；奥罗修斯把它定在约主后 49 年 | 作坊里有「被赶出罗马的人」，也带来罗马的消息 |
| 西拉、提摩太从马其顿来，**带来马其顿弟兄的供给** | 徒 18:5；林后 11:9；腓 4:15 | 有了供给，保罗可以不用天天缝帐棚，「为道迫切」 |
| 会堂里的反对；保罗「抖着衣裳」，搬到会堂隔壁的提多·犹士都家 | 徒 18:6-7 | 城里的地点：会堂、提多·犹士都家 |
| 管会堂的基利司布全家信主 | 徒 18:8 | 事件 |
| 夜里的异象：「不要怕，只管讲」 | 徒 18:9-10 | 保罗的夜晚 |

**保罗的处境，一句话**：一个刚被赶出三座城（腓立比、帖撒罗尼迦、庇哩亚）、在雅典也不算成功的人，在一座陌生的大商港里白天做工，心里挂着一群他回不去的新信徒。

### 3. 哥林多这座城（主后 50 年前后）

| 项目 | 史料与考古 | 游戏可用 |
|---|---|---|
| 罗马殖民城 | 主前 146 年被罗马摧毁，主前 44 年由凯撒重建为「尤利乌斯·哥林多殖民城」；居民多是被释放的奴隶和移民；官方语言是拉丁文 | 城里拉丁文和希腊文混杂 |
| 亚该亚省首府 | 方伯驻在这里（徒 18:12） | 广场上的审判台（βῆμα，徒 18:12） |
| 两个港口 | 西边的利基翁港通往意大利，东边的坚革哩港通往爱琴海（罗 16:1；徒 18:18） | 信差出发的地方 |
| 拖船道 | 横越地峡、把船拖过去的石铺道 | 地理卡 |
| 地峡运动会 | 每两年举行一次，主后 51 年春天有一届；四方的人涌来，需要帐篷 | **推测**：作坊在运动会期间生意忙（Broneer 的推测） |
| 广场上的人群 | 金口狄翁《第 8 篇演说》描写地峡运动会期间，哲士、诗人、算命的、小贩在神庙周围叫卖争辩 | 保罗要和这些「卖弄口才的人」区别开（参帖前 2:3-6） |
| 亚哥林多山上的亚富罗底特庙 | 斯特拉波说有一千名庙妓，**但那是指主前 146 年以前的旧城，而且多半夸大** | 小心使用，不能当作保罗时代的事实 |
| 以拉都铺的路 | 考古发现一块铭文：「以拉都为担任市政官，自费铺了这条路」；他是否就是罗 16:23 的「城内管银库的以拉都」，**有争议** | 地点卡 |
| 肉市 | 林前 10:25 提到「市上所卖的」 | 偶像祭肉的处境 |
| 医神庙 | 出土大量陶制的手、脚等身体部位还愿物 | 城里的信仰生活 |

### 4. 写一封信要多少功夫？

- 保罗的信很长。一般的私人书信只有几十到一百多字；帖前约 1,480 个希腊字，属于很长的信（参 E. R. Richards《Paul and First-Century Letter Writing》）。
- 写信要用执笔人。罗 16:22 提到代笔的德丢；保罗有时在信末亲笔加几句（林前 16:21；加 6:11；帖后 3:17）。
- 纸草、墨水和执笔人的时间都要花钱。
- 当时识字的人大约只占一到两成（W. V. Harris《Ancient Literacy》）。所以信是**念出来给众人听的**（帖前 5:27）。

## 三、信差和这条路

### 1. 古代书信怎样送

- 罗马的官方驿站只送公文，私人的信要托朋友、商人、旅人带。
- 保罗的信通常由他信得过的同工带去：腓比送罗马书（罗 16:1），推基古送以弗所书和歌罗西书（弗 6:21；西 4:7），以巴弗提送腓立比书（腓 2:25）。
- 信差不只是送信，还要**口头补充、回答问题、带回对方的回音**（参西 4:7-9）。
- **帖前的送信人是谁，经文没有记载**。本作的信差克莱翁是故事想象。

### 2. 路上的世界

| 项目 | 史料 | 游戏可用 |
|---|---|---|
| 步行速度 | 每天约 25–30 公里（Casson《Travel in the Ancient World》；ORBIS） | 天数 |
| 航海季节 | 维吉提乌斯说 5 月底到 9 月中最安全，11 月中到 3 月初封海 | 选海路要看季节 |
| 客栈 | 路边客栈名声很坏，常兼作酒馆和娼寮 | 4:3-8 成圣的试探在路上就会遇到 |
| 弟兄的款待 | 信徒彼此接待来往的弟兄（罗 16:2；约叁 5-8） | **4:9-10 的「弟兄相爱」可以做成规则：有弟兄的城可以免费过夜、更安全** |
| 强盗与江河 | 林后 11:26「遭江河的危险、盗贼的危险」 | 路上的事件 |
| 推荐信 | 信差常带着介绍信，让陌生的教会接待他（参罗 16:1-2；林后 3:1） | 道具卡 |

### 3. 往返的意义

- **去程**：信差带着帖前，把保罗的话送到。
- **回程**：信差带回帖撒罗尼迦的近况，包括有人还不做工、有人被「冒我名的书信」惊慌（帖后 2:2；3:11）。这就是下一卷（帖后）的起点。

## 四、收信的人：帖撒罗尼迦城与教会

### 1. 城市

| 项目 | 史料与考古 |
|---|---|
| 建城 | 主前 315 年由卡山德建立，以亚历山大大帝的姊妹帖撒罗尼迦命名 |
| 地位 | 马其顿省首府；主前 42 年因在腓立比战役中站对了边，获得「自由城」地位 |
| 治理 | 由五六位「地方官」（politarchs）治理（徒 17:6）；有铭文为证 |
| 方伯 | 主后 44 年起，马其顿重新成为元老院行省，方伯驻在帖撒罗尼迦 |
| 交通 | 厄纳齐亚大道穿城而过；有港口 |
| 人口 | 估计数万人（各家估计差距大） |
| 宗教 | 凯撒的庙与「罗马与罗马恩主」的崇拜；塞拉匹斯与伊西斯（出土塞拉匹斯庙）；狄俄尼索斯；卡比洛斯（证据多属较晚年代）；犹太会堂（徒 17:1） |
| 考古提醒 | 今天看到的罗马广场是主后 2 世纪的建筑，保罗时代还没有 |

### 2. 教会

| 项目 | 依据 |
|---|---|
| 组成 | 有些犹太人、许多虔敬的希腊人、不少尊贵的妇女（徒 17:4）；但信中看得出多数是「离弃偶像」的外邦人（1:9） |
| 社会阶层 | 多是手艺人（4:11「亲手做工」）。Ascough 推测，教会可能是由一个手艺人的会社整体信主而形成的（推测） |
| 聚会 | 在信徒家中，例如耶孙家（徒 17:5-7） |
| 带领的人 | 「在你们中间劳苦的人，就是在主里面治理你们的」（5:12）；可能是提供房子的恩主 |
| 处境 | 受「本地人」逼迫（2:14）；有人睡了（4:13）；有人不做工（4:11；5:14） |

### 3. 保罗与这城的渊源（全时间线）

| 时间（约） | 事件 | 出处 |
|---|---|---|
| 主后 49/50 年 | 从腓立比经暗非波里、亚波罗尼亚来到；会堂讲论三个安息日；昼夜做工；腓立比人两次送供给；暴乱；夜里去庇哩亚 | 徒 17:1-10；帖前 2:1-12；腓 4:16 |
| 不久 | 反对者追到庇哩亚；保罗从海路到雅典；打发提摩太回帖撒罗尼迦 | 徒 17:13-15；帖前 3:1-2 |
| 主后 50 年 | 在哥林多，提摩太带回好消息；写帖前 | 徒 18:1-5；帖前 3:6 |
| 几个月后 | 写帖后（若为保罗所写） | 帖后 |
| 主后 55–57 年 | 保罗再到马其顿；马其顿众教会「在极穷之间」为耶路撒冷捐献 | 徒 20:1-3；林后 8:1-5 |
| 之后 | 亚里达古、西公都作为代表，与保罗同往耶路撒冷；亚里达古后来与保罗一同坐监 | 徒 20:4；西 4:10 |
| 更后 | 「底马贪爱现今的世界，就离弃我往帖撒罗尼迦去了」 | 提后 4:10 |
